# متریکا — نسخه ۳: صفحه «خانه» و اصلاح «امکانات»

## محتوای تحویل

| فایل | کاربرد |
|---|---|
| `METRICA_HOME_v3.zip` | بسته استقرار؛ ساختار آن دقیقاً مانند پوشه دامنه است: `public_html/` و `metrica_private/` |
| `migrate-home-v3.sql` | ساخت سه جدول جدید (فقط `CREATE TABLE IF NOT EXISTS`؛ هیچ جدول یا داده‌ای حذف یا تغییر نمی‌کند) |
| `DEPLOY-fa.md` | همین راهنما |

`config.php` عمداً **داخل بسته نیست**: فایل واقعی روی هاست (دیتابیس، کلید پیامک، Pattern UID، APP_SECRET) دست نمی‌خورد. این نسخه به هیچ تنظیم جدیدی نیاز ندارد.

## نصب روی DirectAdmin

1. **پشتیبان:** در File Manager پوشه‌های `public_html` و `metrica_private` را Compress کنید و فایل را دانلود کنید. (اختیاری: phpMyAdmin → دیتابیس → Export.)
2. **آپلود:** `METRICA_HOME_v3.zip` را در پوشه دامنه آپلود کنید، یعنی کنار `public_html`:
   `/home/negare29/domains/agahwididiskwksk.ir/`
3. **Extract:** روی فایل ZIP همان‌جا Extract بزنید و جایگزینی (Overwrite) را تأیید کنید. نتیجه:
   ```
   agahwididiskwksk.ir/
   ├── public_html/            index.html، .htaccess، assets/، api/index.php
   └── metrica_private/        app/ (api.php، Home.php و …)، logs/، config.php (همان فایل قبلی شما)
   ```
   هیچ پوشه تودرتویی ساخته نمی‌شود. پس از Extract، فایل ZIP را پاک کنید.
4. **دیتابیس (پیشنهادی):** phpMyAdmin → دیتابیس `negare29_metrica` → Import → `migrate-home-v3.sql`.
   اگر این مرحله انجام نشود، API همین جدول‌ها را بار اول که «خانه» باز شود خودش می‌سازد (کاربر دیتابیس باید اجازه CREATE داشته باشد).
5. **بررسی نصب:** `https://agahwididiskwksk.ir/api/index.php/health` را باز کنید. باید ببینید:
   `"database":"ok"`، `"schema":"ok"`، `"home":"ok"` (یا `"pending"` تا پیش از اولین استفاده، اگر مرحله ۴ انجام نشده)، `"otp":"active"`.
6. **آزمون:** سایت را باز کنید → «خانه» → ورود با شماره موبایل → نام شما در «سلام …، خوش آمدی!» → یک یادآوری ثبت، ویرایش، انجام‌شده و حذف کنید.
7. **پاک‌سازی اختیاری:** دو فایل قدیمی دیگر استفاده نمی‌شوند و می‌توانید حذفشان کنید:
   `public_html/assets/js/13-app.1f587203f9f2.js` و `public_html/assets/js/14-panels.8341fe07e2e7.js`

نام فایل‌های CSS/JS با محتوایشان عوض می‌شود، پس مرورگر کاربران نسخه قبلی را از کش نمی‌خواند.

## فایل‌های تغییرکرده

**جدید**
- `metrica_private/app/Home.php` — داشبورد، یادآوری‌ها، اعلان‌ها (همه پرس‌وجوها محدود به کاربر همان نشست)
- `public_html/assets/js/12b-home.<hash>.js` — صفحه «خانه»
- `public_html/assets/js/04b-i18n-home.<hash>.js` — ترجمه انگلیسی/عربی متن‌های جدید
- `public_html/assets/css/home.<hash>.css` — طراحی «خانه»، پنل یادآوری، چیدمان «امکانات»
- `public_html/assets/img/`: لوگو (فقط نشان، بدون متن)، ساختمان هدر، ساختمان نقشه‌ای بنر، نمودار، سه آیکون مالی، چهار تقویم (WebP شفاف)

**ویرایش‌شده**
- `metrica_private/app/api.php` — مسیرهای `GET /home`، `POST /reminders/save|done|delete`، `POST /notifications/read`؛ گزارش `home` در `/health`
- `public_html/index.html` — قالب «خانه»، پنل یادآوری، ترتیب کارت‌های «امکانات»، ارجاع فایل‌های جدید
- `public_html/assets/js/13-app.<hash>.js` — مسیر «خانه» با هدر اختصاصی و اعلام وضعیت ورود
- `public_html/assets/js/14-panels.<hash>.js` — اعلام پایان بررسی نشست، در اختیار گذاشتن همان لایه API

**بدون تغییر:** OTP، پیامک، نشست هفت‌روزه، خروج، حساب من، تنظیمات، آنالیز ساخت، اشتراک، `.htaccess`ها و `config.php`.

## وضعیت بخش‌ها

**کاملاً عملیاتی**
- ورود: «خانه» بدون ورود باز نمی‌شود و پنل ورود با OTP فعلی باز می‌شود؛ کاربر جدید فقط نامش را وارد می‌کند؛ نشست معتبر (هفت‌روزه) مستقیم وارد می‌شود. API هم بدون نشست معتبر پاسخ ۴۰۱ می‌دهد و پس از خروج دسترسی قطع است.
- نام واقعی کاربر و تاریخ شمسی امروز (منطقه زمانی تهران).
- یادآوری‌ها: ثبت، نمایش، ویرایش، انجام‌شده/بازگردانی، حذف (دو مرحله‌ای)، تاریخ شمسی با تبدیل درست (اسفند ۲۹/۳۰ روزه)، ساعت اختیاری، رنگ تقویم به ترتیب ثبت (آبی، سبز، نارنجی، قرمز، دوباره آبی) که در دیتابیس ثبت می‌شود و با حذف یا رفرش عوض نمی‌شود.
- اعلان‌ها: زنگ، نقطه زرد فقط با اعلان خوانده‌نشده، مینی‌پنل با متن حالت خالی، خوانده‌شدن هنگام باز کردن.
- «شروع پروژه جدید» → «امکانات».
- «امکانات»: «آنالیز ساخت» بالا راست، «تجربه رایگان» بالا چپ، بقیه به ترتیب قبلی؛ کارت‌ها حدود ۸٪ کوچک‌تر در همه اندازه‌ها.

**منتظر بک‌اند پروژه‌ها** (ساختار آماده است، اکنون مقدار واقعی صفر/خالی است)
- سه کارت آمار، «آخرین پروژه‌ها» و «وضعیت مالی پروژه‌ها»: سرور فعلاً ۰ و فهرست خالی برمی‌گرداند (`Home::dashboard()` در `Home.php`). وقتی جدول پروژه‌ها ساخته شد، فقط همان تابع باید از داده کاربر محاسبه کند؛ صفحه قالب‌بندی تومان/میلیون/میلیارد و حلقه پیشرفت را خودش انجام می‌دهد.
- نمودار وضعیت مالی یک تصویر تزئینی با برچسب «نمای تصویری» است، نه داده کاربر.
- رویدادی که اعلان بسازد هنوز وجود ندارد؛ برای ساختن اعلان از سرور: `Home::notify($db, $userId, 'عنوان', 'متن')`.

**پیاده‌سازی‌نشده (عمداً)**
- ارسال اعلان/پیامک در زمان یادآوری. نیاز به Cron Job در DirectAdmin (مثلاً هر ۵ دقیقه) و برای اعلان روی گوشی، Service Worker + Web Push با کلیدهای VAPID دارد. یادآوری‌ها اکنون ثبت و نمایش داده می‌شوند و ادعای ارسال خودکار نمی‌شود.

- اسکرین‌شات در عرض‌های ۳۲۰، ۳۷۵، ۳۹۰، ۴۳۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل؛ بدون اسکرول افقی؛ فونت Estedad بارگذاری‌شده؛ فارسی، انگلیسی و عربی.

روی هاست واقعی آزمون نشده است: ارسال پیامک واقعی، نسخه PHP/MySQL هاست و مجوز CREATE کاربر دیتابیس را پس از نصب با مراحل ۵ و ۶ بررسی کنید.
