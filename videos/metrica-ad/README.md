# METRICA — تبلیغ ۹:۱۶ (سناریوی اول)

تبلیغ سینمایی حدود ۶۷ ثانیه‌ای برای «مِتریکا»، هماهنگ با فایل صوتی گوینده (`assets/audio/voice.mp3`، ۶۴.۹ ثانیه، بدون تغییر).
خروجی: 1080×1920، 30fps، H.264 + AAC، بلندی −14 LUFS.

## ساختار

| مسیر | محتوا |
|---|---|
| `index.html` | ریشه: بوم سه‌بعدی، برچسب‌های متصل به اشیای سه‌بعدی، صدا، میزبان سکانس‌ها |
| `assets/world/*.js` | دنیای سه‌بعدی (Three.js) — همه اشیا با کد و برای همین پروژه ساخته شده‌اند |
| `compositions/s1…s8` | تایپوگرافی فارسی و لوگو هر سکانس (GSAP) |
| `assets/screens/` | شات‌های واقعی سایت (موبایل 390×844@3x با نوار وضعیت، دسکتاپ 1440×900@2x) |
| `assets/brand/` | لوگوی ارسالی کاربر؛ فقط گوشه‌های پس‌زمینه سفید گرد شده (شعاع ۱۴۳px روی 2310×1905) |
| `assets/fonts/` | فونت Peyda، استخراج‌شده از خود سایت مِتریکا |
| `assets/tex/` | بافت‌های PBR رویه‌ای (`tools/make_textures.py`) |
| `assets/audio/` | صدای گوینده، موسیقی (MusicGen محلی)، افکت‌ها (Pixabay، `sfx/CREDITS.md`)، میکس نهایی |

## سکانس‌ها (زمان‌ها از رونوشت کلمه‌به‌کلمه صدا)

1. ۰–۶.۴۵ قلاب: شیرجه از آسمان شهر در غروب به زمین خالی، نقشه طلایی، بالا آمدن اسکلت، توقف لحظه‌ای
2. ۶.۴۵–۱۶.۸ ساختمان نیمه‌ساخت (میلگرد، قالب، داربست، جرثقیل)؛ غروب ← صبح؛ سه شیء «هزینه ساخت / سرمایه موردنیاز / سود احتمالی»
3. ۱۶.۸–۲۵.۱ تبدیل به ماکت سفید روی میز شیشه‌ای سرمه‌ای؛ سه سؤال با سه حرکت دوربین
4. ۲۵.۱–۳۱ جذب داده‌ها به مرکز و ریویل لوگو؛ «تحلیل اقتصادی ساخت‌وساز»
5. ۳۱–۳۸.۴ ورودی‌ها روی گوشی و لپ‌تاپ اختصاصی با صفحه‌های واقعی سایت؛ رشد ماکت با «تعداد طبقات ۶»؛ دکمه واقعی «محاسبه برآورد» و صفحه بارگذاری واقعی
6. ۳۸.۴–۴۷.۴۵ داشبورد سه‌بعدی چهار خروجی، هر کدام روی کلمه خودش (بدون هیچ عدد یا نتیجه ساختگی)
7. ۴۷.۴۵–۵۷.۱ ساختمان تکمیل‌شده در روز با خطوط تحلیل طلایی؛ «دید روشن‌تر، تصمیم آگاهانه‌تر»
8. ۵۷.۱–۶۷ ترکیب نهایی: ماکت + لپ‌تاپ + گوشی، لوگو، شعار در دو ضرب، «موبایل / وب‌سایت»

## نکات صداقت محتوا

- سایت ارسالی صفحه نتیجه/داشبورد ندارد (بعد از «محاسبه برآورد» فقط صفحه بارگذاری است)؛ داشبورد سکانس ۶ نمایش مفهومی چهار خروجی گویندگی است، بدون عدد.
- اپلیکیشن مستقلی در فایل نبود؛ گوشی «نسخه موبایل وب‌سایت» را نشان می‌دهد و برچسبش «موبایل» است.
- شعار روی تصویر «دقیق حساب کن / مطمئن انتخاب کن» است؛ در فایل صوتی جمله «قبل از ساخت حساب کن، بعد تصمیم بگیر» خوانده شده. متن شعار متغیر `slogan1` / `slogan2` در `compositions/s8-end.html` است.

## ساخت دوباره

```bash
python3 tools/make_textures.py assets/tex                 # بافت‌ها
node tools/capture_site.cjs <site.html> <lottie.min.js> <out>   # شات‌های سایت
python3 tools/screens.py <out> assets/screens assets/fonts/Peyda-600.ttf
python3 tools/musicgen_bgm.py assets/audio/music          # موسیقی (CPU، حدود ۲۰ دقیقه)
python3 tools/mix_audio.py                                # میکس → assets/audio/mix.m4a
node tools/frames.cjs <dir> 0 12.5 33.9                   # پیش‌نمایش سریع فریم‌های سه‌بعدی
npx hyperframes check && npx hyperframes render -w 2 -q delivery
```
