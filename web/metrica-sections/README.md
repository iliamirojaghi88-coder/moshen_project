# متریکا — سکشن «ابزارها و خرید اشتراک» و «چرا متریکا؟»

همهٔ بدنه‌ها، منحنی‌ها، نورها، شیشه‌ها، دکمه‌ها و پس‌زمینه‌ها با HTML/CSS/SVG ساخته شده‌اند. تنها تصاویر، PNGهای ارسالی کارفرماست (`assets/img/`، تبدیل‌شده به WebP شفاف بدون تغییر محتوا). فونت: Estedad رسمی (مجوز OFL در `assets/fonts/OFL.txt`).

## فایل‌ها

| مسیر | کاربرد |
|---|---|
| `index.html` | نسخهٔ اجرایی پوشه‌ای (ساخته‌شده از `src/`) |
| `dist/metrica-sections.html` | نسخهٔ تک‌فایلی آفلاین (همه‌چیز جاسازی‌شده) |
| `src/index.html` | منبع markup؛ پوستهٔ کارت «تحلیل اقتصادی» در `src/_econ-skin.svg` |
| `css/metrica.css` | استایل‌ها، چیدمان موبایل/تبلت/دسکتاپ، موج متحرک |
| `js/geometry.js` | هندسهٔ لنگردار کارت‌ها (مختصات مرجع، بدون کشیدگی) |
| `js/metrica.js` | بازچینی پوسته‌ها هنگام تغییر اندازه |
| `tools/build.cjs` | ساخت `index.html` و نسخهٔ تک‌فایلی |
| `tools/qa.cjs` | رندر در اندازهٔ مرجع + بررسی خودکار ۸ عرض |
| `screenshots/` | اسکرین‌شات‌های موبایل/تبلت/دسکتاپ و مقایسه با مرجع |

## ساخت و آزمون

```
node tools/build.cjs
NODE_PATH=$(npm root -g) node tools/qa.cjs <پوشهٔ خروجی>
```

## اتصال به پروژه

دکمه‌ها رفتار ندارند؛ با `data-mtr-action` / `data-mtr-tool` / `data-mtr-feature` به مسیرها وصل شوند. هر کارت یک `article` مستقل است و کلاس‌ها پیشوند `mt-` دارند.
