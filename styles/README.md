# Style systems

Three independent, combinable design + motion systems. Each JSON holds the
tokens a composition reads (palette, type, camera grammar, transitions,
sound). They describe *techniques* distilled from the reference analysis —
they are not templates of the reference videos and must never reproduce
their scenes, people, characters or copy.

Mixing: take `camera` from one and `captions`/`type` from another; keep one
palette per film.
